# Python Projects

Beginner Python projects (file automation & CSV cleaning)

## Projects
- **File Organizer** — scans a folder and moves files into subfolders based on extension. Uses `os` & `shutil`.
- **CSV Cleaner** — loads CSV with pandas, removes duplicates and missing rows, and saves cleaned CSV.

## How to run
1. Put sample files in `FILES/` (for file organizer) or `FILES/csv_files/` (for CSV cleaner).
2. Run `python organiser.py` or `python csv_cleaner.py`.
